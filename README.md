# Atelier Ora — Luxury Heavyweight Apparel & 3D Garment Studio

> Contemporary apparel house engineering custom 500 GSM loopback fleece and architectural outerwear.

## Overview
Atelier Ora is a luxury fashion brand digital flagship designed and engineered by Mobpie. Built with a distinctive warm travertine and oat milk palette, it features an interactive Three.js 3D Garment Studio, real heavyweight fabric lookbooks, and mobile-first e-commerce UX.

## Key Highlights
- **Interactive 3D Garment Studio (Three.js)**:
  - Sculpted streetwear boxy hoodie with natural drape and relaxed arm posture.
  - 360-degree orbit rotation with smooth mobile pan-y scrolling compatibility.
  - 5 Real-time color swatches (Oatmeal, Olive, Espresso, Terracotta, Camel).
  - Wind drape fabric simulation and CAD pattern seam inspection mode.
  - Procedural 500 GSM loopback cotton knit texture and micro-bump mapping.
- **Warm Travertine Aesthetic**: Eliminates generic black-and-white clichés in favor of warm, editorial Italian luxury tones.
- **Essential Apparel Catalog**: High-resolution photorealistic lookbook cards for heavyweight fleece, flight bombers, wool trenches, and suede Chelsea boots.
- **Dedicated Native Mobile App UI**: Mobile navigation dock, smooth drawer cart, and 1-tap checkout.

## Tech Stack
- **Frontend**: HTML5, CSS3, Modern Vanilla JavaScript (ES6+)
- **3D Graphics Engine**: Three.js (r128 WebGL Renderer with ACESFilmic ToneMapping)
- **Deployment**: Vercel Edge Network
